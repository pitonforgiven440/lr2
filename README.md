# Лабораторная работа №2. Веб-сервис «Заболевшие опасным заболеванием по странам»

## Вариант 7

### Предметная область
Заболевшие опасным заболеванием по странам (выздоровевшие, погибшие).

### Модель данных

| Поле       | Тип      | Описание                          |
|------------|----------|-----------------------------------|
| id         | integer  | Идентификатор записи              |
| country    | string   | Страна                            |
| disease    | string   | Название заболевания              |
| year       | integer  | Год                               |
| infected   | integer  | Количество заболевших             |
| recovered  | integer  | Количество выздоровевших          |
| deceased   | integer  | Количество погибших               |

### API

| Метод   | URL                | Описание                                    |
|---------|--------------------|---------------------------------------------|
| GET     | /records           | Все записи (sort_by, order)                 |
| GET     | /records/\<id\>     | Запись по id                                |
| POST    | /records           | Добавить запись                             |
| PUT     | /records/\<id\>     | Обновить запись                             |
| DELETE  | /records/\<id\>     | Удалить запись                              |
| GET     | /stats             | Статистика (avg, max, min) по числовым полям|
| GET     | /info              | Информация о сервисе                        |
| GET     | /apidocs           | Swagger UI                                  |

### Запуск

```bash
pip install -r requirements.txt
python main.py
```

Открыть документацию: http://127.0.0.1:5000/apidocs
